# Catris

A custom Tetris-inspired game developed as a final project for my **Advanced Programming** module.

This project is built using **Java Swing** and is heavily based on the amazing [Java Tetris Tutorial by RyiSnow](https://youtube.com).

# How to Run the Project

Please note that this repository **does not contain a pre-compiled executable file**. You will need to run the source code directly:

1. Clone or download this repository to your local machine.
2. Open the project folder in your preferred Java IDE (such as IntelliJ IDEA, Eclipse, or NetBeans).
3. Locate `Main.java` inside the source files.
4. Run the file to launch the game.

*This repository also includes a small presentation slideshow that was originally used to pitch the game concept to the project team.*
